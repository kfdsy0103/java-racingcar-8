# java-racingcar-precourse

## 입출력 기능
- 자동차 이름 입력 기능
  - 구분자(,)를 기준으로 이름을 나눔
- 시도 횟수 입력 기능
  - 양수인 정수
- 게임 실행 결과 출력 기능
  - 우승자 목록을 받아 출력 포맷에 맞게 출력

## 사용자의 입력값 파싱 기능
- 자동차 이름 파싱 기능
  - 구분자(,) 기준으로 분리
  - 검증기로 검증 후 이름 리스트 반환
- 시도 횟수 파싱 기능
  - 검증기로 검증 후 숫자 반환

## 입력값 검증 기능
- 자동차 이름 유효성 검사
  - 5자 초과 혹은 빈 문자열인 경우 예외처리
- 시도 횟수 유효성 검사
  - 양수인 정수만 입력받을 수 있도록 처리

## 경주 자동차 클래스 정의
- 자동차 이름
- 앞으로 이동한 칸 수

## 경주 게임 시뮬레이션 기능
- 참가 자동차 및 시도 횟수를 받아 게임 진행
- 중간 진행상황 출력
- 최종 우승자 출력
